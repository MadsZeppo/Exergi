# Merchant Validation Protocol V1

1. Ingest at least 12 months where possible.
2. Run Data Trust and reconcile relevant source totals.
3. Run point-in-time rolling backtests.
4. Freeze prediction capabilities.
5. Build current customer and population states.
6. Run deterministic opportunity detection.
7. Merchant selects one material opportunity.
8. Define two or three curated actions.
9. Freeze the randomized experiment and pre-outcome ledger record.
10. Run prospectively without optional stopping.
11. Freeze and version outcomes.
12. Validate assignment, balance, completeness, contamination and sample size.
13. Estimate primary ITT effect.
14. Calculate incremental contribution profit when economics are complete.
15. Compare pre-experiment expectation with randomized reality.
16. Append the result and MerchantLearningRecord.

Treatment success is not the validation criterion. A valid negative experiment is useful product evidence.
