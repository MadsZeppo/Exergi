# V7.3 Merchant Shadow Protocol

The immutable V7.2 merchant design-partner contract is preserved without modification. Shadow mode
remains read-only, requires timestamped pretreatment features and logged randomization propensity,
reconciles revenue, returns, discounts, COGS, fulfillment, payment fees, and campaign cost into
contribution profit, requires explicit merchant approval, waits for outcome maturity, and forbids
autonomous shop changes.

No V7.3 gate was frozen, so shadow mode must display BAU and `NOT ENOUGH EVIDENCE`; it may not present
a V7.3 ACT recommendation. Existing fail-closed contract tests remain part of the full QA suite.
