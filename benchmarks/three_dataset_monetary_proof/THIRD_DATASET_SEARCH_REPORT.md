# Third randomized monetary dataset qualification

Final qualification status: `THIRD_MONETARY_DATASET_NOT_FOUND`.

No monetary outcome column was opened during this phase.

## Named Yahoo candidate

The official INFORMS record for *When Less Is More: Data and Power in Advertising
Experiments* documents a randomized field experiment involving approximately three million
retail customers and links supplemental data. Crossref independently confirms the publisher,
DOI and supplemental-data statement.

The official supplemental payload could not be acquired reproducibly: direct publisher access
returned its access-security page, and no official row-level archive, checksum, schema or reuse
license could be verified. Paper tables or the public manuscript are not substituted for row-level
data.

## Selected alternative

The strongest updated official-repository candidate was OpenICPSR project 113141,
*Team Incentives and Performance: Evidence from a Retail Chain*.

Its official description provides strong design metadata: 193 shops, randomized team bonuses,
and sales/profit outcomes. The complete public V1 file listing, however, contains only one README
and nine Stata programs. There is no `.dta`, `.csv`, assignment manifest, baseline table or
unit-level monetary file. Project download additionally redirects to ICPSR login.

Without data bytes, Exergi cannot verify duplicates, sample-ratio mismatch, assignment,
propensities, timing, attrition, contamination or create disjoint DEVELOPMENT/VALIDATION units.
The candidate therefore fails before any outcome access.

## Bounded search record

The updated search checked the official publisher/SSRN trail, OpenICPSR, OSF, AEA-associated
archives, Harvard Dataverse, Zenodo, INFORMS supplemental material and author-controlled pages.
It also reconciled the repository's prior official-source audits:

- MT-LIFT: official payload unavailable;
- Zenodo 13993677: required transaction files absent;
- Dominick's: randomized assignment cannot be reconstructed from public movement files;
- Criteo/Open Bandit: non-monetary conversion/click rewards;
- prior proprietary retail RCT papers: no official row-level package found.

The contract was not weakened, no unofficial mirror was used, and no fourth candidate will be
opened to replace an unfavorable result.
